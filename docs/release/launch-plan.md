## 4. 回滚方案

### 4.1 回滚触发条件

**立即回滚：**
- P0 故障（系统不可用）
- 消息处理成功率 < 90%
- 数据丢失或损坏
- 安全漏洞

**考虑回滚：**
- P1 故障（核心功能不可用）
- 消息处理成功率 90%-95%
- 性能严重下降（响应时间 > 10s）
- 用户投诉激增

### 4.2 回滚步骤

**快速回滚（5 分钟内）：**

```bash
# 1. 切换流量回旧版本
kubectl set image deployment/copaw copaw=copaw:v1.0

# 2. 停止新版本服务
systemctl stop copaw-v2

# 3. 启动旧版本服务
systemctl start copaw-v1

# 4. 验证回滚成功
curl http://localhost:8000/health
```

**回滚检查清单：**

- [ ] 流量已切回旧版本（100%）
- [ ] 旧版本服务正常运行
- [ ] 监控指标恢复正常
- [ ] 用户影响最小化
- [ ] 问题原因已记录
